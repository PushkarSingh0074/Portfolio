# Pushkar Singh — Portfolio

Personal portfolio of Pushkar Singh, Data Scientist and Machine Learning Engineer.

**Live site:** https://pushkarsingh0074.github.io

## Featured work

- **VisionAssist AI** — multi-model computer vision platform (PyTorch, Florence-2, YOLOv8, PaddleOCR, FastAPI, Cloud Run GPU)
- **Harvey** — local-first voice AI agent for Windows (Qwen3 on llama.cpp, faster-whisper, Kokoro TTS, speaker verification)
- **Genesis Prep AI** — LLM-powered interview preparation platform (Gemini, React, Node.js, MongoDB)

## Development

```bash
npm install
npm run dev
```

All content is in `src/data.js`. Pushing to `main` builds and deploys the site with GitHub Actions.
